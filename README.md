# Esencia Viva — Landing Page

Landing page oficial de **Esencia Viva — El Guacamole Colombiano**. Guacamole 100% artesanal hecho con aguacate papelillo. Pedidos por WhatsApp en Cali, Colombia.

## Estructura

Todo el sitio vive en un solo archivo: `index.html`. No requiere build, dependencias ni servidor especial — las imágenes y la tipografía de marca van embebidas dentro del propio archivo, así que funciona en cualquier hosting estático.

## Publicar con GitHub Pages

1. Sube este repositorio a GitHub.
2. En el repositorio: **Settings → Pages**.
3. En "Build and deployment", elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En uno o dos minutos la página queda disponible en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.

Para usar un dominio propio (por ejemplo `esenciaviva.co`), configúralo en la misma pantalla de Pages en "Custom domain".

## Editar contenido

Los textos, precios y enlaces de WhatsApp están directamente en el HTML (busca `wa.me/573103235402` para los enlaces de pedido). Los estilos están en el bloque `<style>` del mismo archivo.
